# Chrome Game Extension

This project is a simple Chrome extension that implements a game. Below are the details of the project structure and instructions on how to install and use the extension.

## Project Structure

```
chrome-game-extension
├── src
│   ├── index.html        # Main HTML document for the game interface
│   ├── script.js        # JavaScript code for game logic and interactions
│   ├── style.css        # CSS styles for the game layout and design
│   └── manifest.json    # Configuration file for the Chrome extension
└── README.md            # Documentation for the project
```

## Installation

1. Clone the repository or download the project files.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable "Developer mode" by toggling the switch in the top right corner.
4. Click on "Load unpacked" and select the `chrome-game-extension/src` directory.
5. The extension should now be loaded and ready to use.

## Usage

- Click on the extension icon in the Chrome toolbar to start the game.
- Follow the on-screen instructions to play.
